# Minstrel v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Minstrel v1: users add their own provider keys, make songs, and play and keep them.

**Architecture:** One Vercel project (Hobby) with two services: Next.js in `apps/web` and NestJS in
`apps/api`. Neon Postgres keeps the data, and Cloudflare R2 keeps the audio. Provider callbacks, a sync
on read, and one daily cron sweep move each generation to its end state.

**Tech Stack:** pnpm 11 + Turborepo, Node 24, NestJS 12, Next.js 16, React 19, Drizzle + `pg`, Better
Auth, Zod, `@vercel/functions`, AWS SDK v3 (R2), Vitest 4, Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-minstrel-v1-design.md`. Read the spec section that each task
names. This plan gives the decisions. The spec gives the full rules and the exact copy.

## Global Constraints

- All routes start with `/api`. Each error body is `{ code, message }` with the codes and copy of spec §8.
- No API response and no log line contains a provider key. The UI shows `key_last4` only.
- Each outbound call to a provider or to an audio URL goes through `safeFetch` (spec §7.3).
- Each query for a connection, generation, or track filters on the session `user_id`. Another user's row
  gives `404`.
- IDs are UUID v7 from the Postgres 18 `uuidv7()` default. All times are `timestamptz`.
- Lease, poll, and timeout times use Postgres `now()`, never the clock of the function.
- Hobby values: function limit 300 s. Sync lease 90 s. Backoff 60 s, 120 s, then 300 s. Timeout 30
  minutes from submit. ElevenLabs length 5–180 s, call abort 240 s, lease 6 minutes, 4 running per user.
  The sweep starts no new work after 240 s.
- Work after a reply goes through `BackgroundWork` (Task 13), never a bare promise.
- `apps/api` is ESM: relative imports end in `.js`.
- Commits use Conventional Commits. Do not add a `Co-Authored-By` line or any AI attribution.

## Conventions

- **TDD cycle for each task:** write the tests that the task names, run them and see them fail,
  implement, run the check, see it pass, then commit.
- **Test commands.** Run one file at a time. `<pkg>` is `api`, `web`, or `shared`.
  - Unit: `NODE_OPTIONS=--max-old-space-size=1024 pnpm --filter @minstrel/<pkg> exec vitest run <file> --maxWorkers=1`
  - API integration: `NODE_OPTIONS=--max-old-space-size=1024 pnpm --filter @minstrel/api exec vitest run --config vitest.config.e2e.ts <file> --maxWorkers=1`
  - Typecheck: `NODE_OPTIONS=--max-old-space-size=2048 pnpm turbo run typecheck --concurrency=1`
- In each task, "Check" names the test file. Use the command that matches it.
- API integration tests need `docker compose up -d db` (Task 4) and use `TEST_DATABASE_URL`.
- **Review: yes** marks a task that touches auth, keys, money, or concurrency. Review it with the
  strongest model before the next phase.

## Review Focus

These are inputs that the spec does not name but that users will meet. The test for each is in the task
in brackets.

1. The provider callback arrives before the submit saves `provider_task_id`. The generation must stay
   due, not fail. [Task 37]
2. A callback and a sync return the same track twice. The track must exist once. [Task 37]
3. The audio URL returns an HTTP error or a file over 50 MB. The track must become `copy_failed`, and the
   player must keep the provider URL. [Task 36]
4. The user deletes a connection while a song is in progress. The song must end as `connection_removed`.
   [Task 37]
5. The user clicks "Make song" two times quickly. Only one request must go out. [Task 30]

## Not in this plan

The design canvas shows these items, but the spec does not. Add them to the spec first if you want them:
a cover image upload, an undo snackbar after a delete, and the Contact, Terms, and Privacy pages. The
canvas also uses Geist and uppercase labels, but spec §10.2 says the system font and sentence case.
Task 24 follows the spec until the owner decides.
